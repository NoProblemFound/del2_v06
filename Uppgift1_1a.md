# HTML- element på W3School bilden
Utifrån bilden har sidan troligen följande element


| Element | Funktion |
|----------|----------|
| `<!DOCTYPE html>` | HTML5-deklaration |
| `<html>` | Rot-element |
| `<head>` | Metadata |
| `<body>` | Sidans innehåll |
| `<h1>` | Rubrik |
| `<h2>` | Underrubrik |
| `<p>` | Brödtext |
| `<Script>` | javascript |
| `<img>` | bild |
| `<svg>` | Kanske använder man denna för att skapa icon |
| `<div> och <a>` | För menyer med länkar |
| `<nav> <ul>`  | Kanske man använder dessa element för navigering |
| `<br>` | Kanske för radbrytning |
| `<button>` | knappar |
| `<style>` | Snygga till sidan med CSS |
