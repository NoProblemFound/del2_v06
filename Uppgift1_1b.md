# HTML-element som syns på Wikipedia-sidan

Utifrån bilden på uppgiften används sannolikt följande HTML-element:


| Element | Funktion |
|----------|----------|
| `<!DOCTYPE html>` | HTML5-deklaration |
| `<html> <head> <body>` | Dokumentstruktur |
| `<h1> <h2>` | Rubrik, underrubrik|
| `<p>` | Brödtext |
| `<img>` | bild |
| `<svg>` | Kanske använder man denna för att skapa icon |
| `<div> och <a>` | För menyer med länkar |
| `<nav> <ul>`  | Kanske man använder dessa element för navigering |
| `<br>` | Kanske för radbrytning |
| `<aside>` | sidotexten |
| `<style>` | Kanse lite CSS för att snygga till sida?|
